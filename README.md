# 借壳 / Borrowed Shell

**[直接试玩](https://mengpingchen954-ops.github.io/borrowed-shell/)** · [构建与部署](https://github.com/mengpingchen954-ops/borrowed-shell/actions)

原创科幻潜入动作解谜游戏的 **PC 浏览器可玩版**。Three.js 负责 2D 俯视渲染，Vite 构建，所有规则与音效在浏览器本地运行，无后端、无真实 AI 服务。

你是一段逃亡意识。借用清洁、搬运与安保机体，潜入设施救出被囚禁的“织光”，再抵达撤离升降台。

## 启动与构建

需要 Node.js 22.12+。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。生产构建：

```sh
npm run build
npm run preview
```

构建输出在 `dist/`。必须通过 HTTP/HTTPS 服务打开，不能直接双击 `index.html`。相对资源地址支持 GitHub Pages 仓库子路径。GitHub Actions 会执行单元测试、构建与 Pages 发布。

## 操作

| 输入                                | 动作                            |
| ----------------------------------- | ------------------------------- |
| WASD / 方向键                       | 移动                            |
| Q / 点击场景中的机体 / 点击机体按钮 | 选择连接目标                    |
| E                                   | 确认意识转移                    |
| 空格                                | 使用身体能力或操作附近设备      |
| M                                   | 打开 / 关闭设施图，同时暂停模拟 |
| Esc                                 | 暂停 / 继续，或关闭地图         |
| Enter                               | 开始、失败后恢复、通关后重玩    |

音量与减少动态效果位于开始和暂停菜单。鼠标不是通关必需条件。游戏按 PC 键盘操作设计，没有手机虚拟摇杆。

## 规则

- **清洁机**：碰撞半径 0.29 米，速度 3.15 米/秒；能穿窄风道、操作维护接口；安静，不能搬货。
- **搬运机**：碰撞半径 0.65 米，速度 2.35 米/秒；搬货时碰撞半径扩大到 0.9 米且减速；能搬起实体货箱、放到压力板、启动货运登记台；无法进风道。
- **安保机**：碰撞半径 0.49 米，速度 2.85 米/秒；通过身份门、操作身份台；空格可干扰视线内 6.5 米的巡逻机 4.5 秒，冷却 7 秒；不能搬货或进风道。
- **连接**：10 米范围，目标已解锁且无人控制；实体墙、风道格栅、关闭的门和货箱阻断信号。没有穿墙中继；所有机体都遵守同一连接规则。抱着货箱时须先放下再转移。
- **巡逻**：巡逻、怀疑、追踪、搜索和返回。视锥被墙和货箱截断；警觉逐渐累积，发现后有逃脱时间。大机体的移动也会引起近距离注意。
- **病毒**：条纹区逐渐增加暴露，安保机每秒 +8，其他机体每秒 +11；离开后每秒 -5。达到 100% 才崩溃。暴露随意识保留，换壳不会清空病毒。
- **备份**：开局有初始备份；安全备份台保存整关快照，包括所有机体、当前控制权、门、进度、实体货箱、敌人状态、生命与暴露。恢复会整体回滚。备份仅保存在本次页面会话中，刷新后重新开始；设置在本机保存。

## 美术与音效

全部美术为原创代码绘制：设施地面、实体墙、带栅格风道、三种机器人、巡逻机、货箱、设备与意识囚笼使用 Canvas 贴图，场景由 Three.js 正交镜头、平面网格、信号连接线和裁剪视锥组合。开始界面复用同一套机体美术。转移、搬运、告警、干扰、备份、解救和通关反馈由 Web Audio 合成。

本次环境没有可调用的 imagegen 工具，因此按需求允许的程序化方案完成。没有使用外部 IP、远程字体、远程素材或付费服务。美术实现位于 `src/render.js`，声音位于 `src/main.js`。

## 验证

```sh
npm test
npm run test:browser
```

浏览器测试默认需要 `npm run dev -- --port 5187`，使用 Playwright Chromium。也可设置 `GAME_URL` 检查生产或线上版本。测试通过实际 Q/E、空格、方向键、Esc、Enter 操作，结合确定性模拟步进完成完整路线。测试专用接口只在 URL 含 `?test=1` 时启用，正常会话不暴露。

生产子路径检查：先 `npm run build`，然后运行 `node tests/serve-build.mjs`；测试地址设为 `http://127.0.0.1:5188/borrowed-shell/`。

验收详情与当前限制见 [QA.md](QA.md)。

4. **维护旁路**：连接备用清洁机，操作隔离旁路接口。此操作开启窄风道，并切断南侧巡逻机供电。穿过风道，沿检修折廊绕到东侧，再向北抵达囚笼。这条路可保持零病毒暴露。
5. **感染直通**：留在安保机中，绕过中枢机柜，前往北侧身份门。按视野与冷却时机使用脉冲，直接穿过条纹感染区，及时离开即可降低暴露。撤离时留好脉冲，防止东侧巡逻机贴身追击。
6. 靠近囚笼按空格，保持靠近 2.4 秒完成解封。沿东侧向南，穿过新开启的撤离锁，在升降台按空格通关。
